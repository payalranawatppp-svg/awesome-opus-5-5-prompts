# The Old Way vs. Tooth Referral · 8-second clips + Google Flow

12 clips of 8 seconds (about 1:36), vertical 9:16, one male host in a dim, warm studio, in the style of the reference reel: for each problem he points to the top-LEFT of the frame for the traditional way (“Don’t…”), returns to rest, then points to the top-RIGHT for the Tooth Referral feature (“Do…”), holding each point for the whole line, like the reference reel. The brand name is said only twice (clips 01–02). Every clip starts on the last frame of the one before, so the clips cut together as one continuous take. No graphics are generated: the labels and icons go in during the edit.

## How to use this

- Clip 01’s prompt contains the full host avatar prompt, the background prompt and the start frame, so it sets the look for the whole series. Generate clip 01 first, then 02–12 in order.
- From clip 02 on, the prompt only says to continue from the last image of the previous clip: in Flow, use the previous clip’s last frame as the start image (extend / use last frame).
- Sides are as the viewer sees the video: “Don’t” = LEFT side of the frame, “Do” = RIGHT side. Put the Don’t labels top-left and the Do labels top-right, above each finger.
- Every clip, second by second: rest pose → right hand points top-left and HOLDS through the whole Don’t line → hand back to rest → left hand points top-right and HOLDS through the whole Do line → back to rest. Every clip starts and ends in the same rest pose, so the cuts are invisible.
- Every clip is one “Don’t … / Do …” pair, like the reference reel: the Don’t half names the traditional waste, the Do half names the Tooth Referral feature. Each pair fits in about 7 s of the 8 s clip.
- The name “Tooth Referral” is spoken only in clips 01 and 02; after that, the logo and labels carry the brand.
- If Flow’s voice drifts between clips, re-record the full voice-over below in ElevenLabs with one male voice and lip-sync to it.
