# The Old Way vs. Tooth Referral · 8-second clips + Google Flow

Nine 8-second clips (about 72 s), vertical 9:16, one male host in a dim, warm studio, in the style of the reference reel: for each problem he points to the top-right of the frame for the old way (3–4 very short lines), then to the top-left for the Tooth Referral benefit (one sentence). Every clip starts on the last frame of the one before, so the clips cut together as one continuous take. No graphics are generated: the labels and icons go in during the edit.

## How to use this

- Generate the 3 reference images first (studio background, host avatar, host start frame), then the clips in order 01–09.
- For each clip after 01, use the last frame of the previous clip as the start image (in Flow: extend / use last frame), plus the background and avatar images as ingredients.
- His LEFT hand appears on the RIGHT of the frame: put the "old way" labels top-right and the "Tooth Referral" labels top-left, above each finger.
- Every prompt ends in the same rest pose, so cuts between clips are invisible.
- If Flow’s voice drifts between clips, re-record the full voice-over below in ElevenLabs with one male voice and lip-sync to it.
